1. Problem Statement
================================================================================

Develop an Iris Flower Classifier ML web application using Python, Flask, and
scikit-learn, and implement the complete DevOps lifecycle on a Windows PC.
Use Git for version control, GitHub for source-code hosting, Docker for
application containerization, and Jenkins for automating the build, testing,
and deployment pipeline. Configure each tool, verify its installed version,
and execute the necessary Windows commands to demonstrate how the application
moves from development through CI/CD to deployment.

--------------------------------------------------------------------------------
5. Jenkins — Continuous Integration and Continuous Deployment
--------------------------------------------------------------------------------

1. Environment Setup
   - Install Java JDK 17+ from https://adoptium.net/
   - Install Jenkins from https://www.jenkins.io/download/
   - Access Jenkins at http://localhost:8080 and complete initial setup.
   - Install plugins: Git, Docker Pipeline, Pipeline.
   - Configure Git and Docker tool paths in Manage Jenkins > Global Tool Configuration.

2. Commands to Run on Windows

   For Jenkins installed directly on Windows:

   java -version
   git --version
   docker --version
   net start jenkins

   For Jenkins running as a Docker container named jenkins:

   docker run -d --name jenkins -p 8080:8080 -p 50000:50000 -v jenkins_data:/var/jenkins_home jenkins/jenkins:lts
   docker ps
   docker logs jenkins
   docker start jenkins
   docker exec jenkins java -version
   docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword

3. Running the Complete Project (Step by Step)
================================================================================

Step 1: Clone the repository
   git clone https://github.com/PrafullHarer/MLDevOPS-Lab-ISE-2.git
   cd MLDevOPS-Lab-ISE-2

Step 2: Install Python dependencies
   pip install -r requirements.txt

Step 3: Train the ML model
   python train_model.py

Step 4: Run the Flask application
   python app.py
   (Open http://localhost:5000 in browser)

Step 5: Run unit tests
   python -m pytest tests/ -v

Step 6: Build Docker image
   docker build -t iris-classifier .

Step 7: Run Docker container
   docker run -d --name iris-classifier -p 5000:5000 iris-classifier

Step 8: Verify deployment
   curl http://localhost:5000/health

Step 9: Push to GitHub
   git add .
   git commit -m "Initial commit: Iris Flower Classifier ML web app"
   git remote add origin https://github.com/PrafullHarer/MLDevOPS-Lab-ISE-2.git
   git branch -M main
   git push -u origin main

Step 10: Create Jenkins Pipeline
   - Open http://localhost:8080
   - New Item > Pipeline > Name: Iris-Classifier-Pipeline
   - Pipeline > Definition: Pipeline script from SCM
   - SCM: Git
   - Repository URL: https://github.com/PrafullHarer/MLDevOPS-Lab-ISE-2.git
   - Branch: */main
   - Script Path: Jenkinsfile
   - Save > Build Now
